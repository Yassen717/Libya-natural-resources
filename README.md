An interactive platform for exploring Libya's natural wealth — oil, natural gas,
groundwater, minerals, and agriculture — with charts, an interactive map, and a
searchable resource database.

## Features

- **Overview** — key facts, achievements, and the economic impact of Libya's
  natural resources.
- **Interactive Map** — resource locations across Libya with hover tooltips,
  type filters, and a details panel.
- **Statistics** — interactive pie, line, and bar charts (Recharts) covering
  production mix, yearly trends, and regional distribution.
- **Resource Database** — searchable, filterable database with technical data
  per resource (depth, quality, extraction method).
- **Agriculture** — cultivated-land statistics, crop distribution donut chart,
  and key challenges.

## Tech stack

- **React 19** + **TypeScript** — modern, type-safe UI
- **Vite 8** — fast dev server and builds
- **Tailwind CSS 4** — utility-first styling via `@tailwindcss/vite`
- **Recharts 3** — data visualization
- **Lucide** — icons

## Getting started

```bash
npm install
npm run dev
```

Other scripts:

```bash
npm run build   # typecheck + production build
npm run lint    # eslint
npm run preview # preview the production build
```
